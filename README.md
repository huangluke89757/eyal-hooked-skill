# eyal-hooked

> 把《上瘾》（Hooked: How to Build Habit-Forming Products）的方法论固化为可随时调用的 AI 技能包。

## 这是什么

基于尼尔·埃亚尔（Nir Eyal）的「上瘾模型（Hook Model）」——**触发 → 行动 → 多变的酬赏 → 投入** 四步循环，帮助用户养成使用习惯、提升产品留存。

## 有什么价值

- **从维生素到止痛药**：把"吃了更好"做成"不吃不行"
- **可诊断的四步模型**：留存低时精确定位是哪一环断了
- **福格行为模型 B=MAP**：动机 / 能力 / 触发，可拆解"用户为什么不动"
- **多变的酬赏原理**：不是酬赏本身，是渴望酬赏时的紧张感；多变性放大渴望
- **可落地的习惯测试**：5% 基线 + 习惯路径，把改产品从拍脑袋变成数据驱动
- **含道德护栏**：操控模式四象限，先问"我该不该"，再问"我能不能"

## 怎么用（触发词）

- 描述场景：「我的 App 用户第二天就流失了，问题出在哪？」
- 问框架名：「上瘾模型」「福格行为模型」「多变的酬赏」「外部触发」「习惯测试」
- 指定章节：`ch01` ~ `ch08`
- 快速决策：读 `cheatsheet.md` 的四步断点诊断树

## 适用边界

适合需要用户频繁主动参与的产品（社交、内容、工具、游戏、SaaS）。不涵盖一次性交易型产品的增长方法、商业模式与客户获取成本。
