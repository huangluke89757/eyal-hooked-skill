# ch03 · 行动：人们在期待酬赏时的直接反应

> 核心命题：触发提示了方向，但如果用户没有付诸行动，触发就未能生效。要让行为发生，动机、能力、触发三者缺一不可。

---

## 一、福格行为模型：B = MAP

斯坦福大学说服技术研究实验室主任 **福格博士（B.J. Fogg）** 的行为模型：

```
B = MAP
B = Behavior（行为）
M = Motivation（动机）
A = Ability（能力）
P/T = Prompt/Trigger（触发）
```

**三者缺一不可**，否则人们无法跨过"**行动线**"，即不会实施某种行为。

**经典例子（手机响了却没接）**：

| 没接的原因 | 缺失要素 | 说明 |
|---|---|---|
| 手机在包里一时找不到 | **能力（A）** 被限制 | 够不着 |
| 以为是推销电话不想接 | **动机（M）** 不足 | 不愿接 |
| 铃声被设为静音 | **触发（T）** 未出现 | 根本没听见 |

---

## 二、动机（M）：决定你是否**愿意**行动

福格认为，驱使我们行动的核心动机不外乎**三组**（每组两端像杠杆，上下摆动改变行为概率）：

1. **追求快乐，逃避痛苦**
2. **追求希望，逃避恐惧**
3. **追求认同，逃避排斥**

**广告是动机的放大镜**：

| 案例 | 利用的动机 |
|---|---|
| 奥巴马 2008 竞选海报（谢波德·费尔雷设计，凝望远方 + "希望"） | **希望** |
| "性卖点"广告（维多利亚的秘密、GoDaddy、汉堡王） | **快乐/窥探欲**——但只对部分人群有效（青春期男孩是重点目标，其他人可能反感） |
| 百威啤酒（三男携手为国家队助威） | **认同/社交凝聚力** |
| 摩托车安全头盔广告（残疾男"我不想戴头盔，那样看起来很傻"） | **恐惧**（负向情绪做动机，效果甚佳） |

> ⚠️ **重要提醒**：能成为某些人行为动机的东西**未必适用于另一些人**。你必须知道自己的目标客户到底需要什么。

---

## 三、能力（A）：能力即**简洁性**

- 行为的复杂程度越低（无论体力还是脑力），被重复的可能性越大。
- **丹尼斯·豪普特利《创新轻松三步法》**：
  1. 了解人们使用某个产品或服务的原因
  2. 列举出用户使用该产品时的**必经环节**
  3. **做减法**——把无关环节全部删除，直至将使用过程简化到极致

> 结论：**越简单的东西越受欢迎**。凡是能以最简便方式享用到的产品，一定是使用率最高的。

**史证**：几十年前拨号上网（要等半分钟到一分钟）被视为神明，今天没人能忍受——因为大家对即时高速接入习以为常。

---

## 四、行动阶段的设计启示

1. **先问"最简单的操作是什么"**：在期待酬赏时，用户可采取的最简单操作行为是什么？
2. **减少思考时间**：减少有关下一步行动的思考时间 = 提高行为发展为**无意识习惯**的概率。
3. **选项做减法**：太多或无关的选项让用户游移不定，甚至罢手。
4. **不要忽视能力**：触发生效 + 动机强烈，用户仍常常不按期望轨迹前进——多半是**可行性不足**（能力不够，产品太难用）。

---

## 五、现在开始做

1. 画出你希望用户完成的**核心行为**，用 B=MAP 逐项打分：动机够吗？能力够吗？触发到位吗？
2. 列出用户完成该行为的**所有必经环节**，逐项问"这步能删吗"？
3. 你的目标用户的**核心动机**属于三组中的哪一组？有没有把动机用在了对的人群上？
4. 用户从"想做"到"做成"之间，**摩擦**在哪一步？

---

## 关键术语

- **行动线**：动机、能力、触发三者交汇的临界线；跨不过去，行为就不会发生。
- **B=MAP**：福格行为模型公式（部分版本写作 B=MAT，T 即 Trigger）。
